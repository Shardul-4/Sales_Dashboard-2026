# Sales Analytics Dashboard

## 📊 Project Overview

This project is an interactive **Sales Analytics Dashboard** built using **Microsoft Power BI**. The dashboard analyzes sales performance across different months, regions, product categories, products, and sales channels.

The main objective of this project is to transform raw sales data into meaningful business insights through interactive visualizations and KPIs.

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculations and KPIs
- **Data Modeling**
- **Data Visualization**

## 📈 Dashboard KPIs

The dashboard provides an overview of:

- **Total Sales:** 3M
- **Total Quantity:** 8K
- **Average Revenue:** 1.73K
- **Total Orders:** 2,000

## 📊 Dashboard Analysis

### 1. Monthly Revenue Analysis
Analyzes revenue performance across different months to identify high-performing and low-performing periods.

### 2. Regional Revenue Analysis
Compares revenue generated across different regions:

- Central
- North
- East
- South
- West

### 3. Product Category Analysis
Analyzes revenue across different product categories such as:

- Computers
- Monitors
- Networking
- Storage
- Accessories
- Office Supplies

### 4. Product Performance
Identifies products generating the highest revenue and helps compare individual product performance.

### 5. Sales Channel Analysis
Compares revenue generated through different sales channels:

- Online
- Corporate Sales
- Retail Store
- Marketplace

## 🔍 Key Insights

- Monthly revenue varies significantly throughout the year.
- Regional performance can be compared to identify the strongest revenue-generating regions.
- Product-level analysis highlights the products contributing most to overall revenue.
- Different sales channels contribute differently to total revenue.
- Product category analysis helps identify categories with higher revenue contribution.
